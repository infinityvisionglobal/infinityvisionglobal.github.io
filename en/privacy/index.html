2. General principle

Lemar does not require a user account. Learning progress, settings and personal app data are generally stored on the device used. In its current feature set, Lemar does not use advertising, analytics services or user tracking.

3. Local app data

Depending on the functions used, Lemar may locally store information relating to the in-app profile, learning progress, favorites, quiz and learning statistics, settings, notes, word lists and downloaded content.

This data is not automatically transmitted to Infinity Vision Agency GbR as a personal user profile.

4. Save data

Lemar allows users to create a save state on the device as a code or file and restore it later. Such a save state may contain personal app data. Lemar does not automatically upload it to a server operated by Infinity Vision Agency GbR. The user decides whether to share it.

5. Microphone and speech input

The microphone is used when the user starts a corresponding pronunciation or speech-input function and grants access. Depending on the device and operating-system settings, speech input may be processed locally or by the relevant operating-system provider.

6. Photos and files

Users may voluntarily select images or save content created by Lemar on their device. Access occurs in connection with the function selected by the user.

7. Local notifications

Lemar may display local reminders at the user's request. The operating system may request permission to show notifications. Lemar does not use its own push-notification server for this purpose.

8. Online audio files

Some learning audio files are provided through ImageKit. When such a file is requested, a connection to ImageKit is established and technically necessary connection data is generated. Lemar does not transmit personal learning progress or a Lemar user ID in this process.

9. Currency converter

When the currency converter is opened, Lemar may request current exchange-rate data from open.er-api.com. Personal learning progress and Lemar user identifiers are not transmitted to that service. Technically necessary connection data is generated when an internet service is accessed.

10. Optional external text-to-speech

If the user configures and uses an external speech service, the content required for the requested speech output is transmitted to the service selected by the user. This may include Microsoft Azure Speech or a TTS server specified by the user. Further processing is governed by the service used.

11. Legal bases

Where personal data is processed for a function requested by the user, processing is carried out in particular to provide that function under Article 6(1)(b) GDPR. Where Lemar asks for consent, processing is based on Article 6(1)(a) GDPR and consent may be withdrawn with effect for the future. Where processing is necessary for legitimate interests, Article 6(1)(f) GDPR may apply.

12. Storage and deletion

Locally stored app data generally remains on the device until it is removed using an available deletion or reset function or the app and its app data are deleted. Data generated through external services may be subject to the rules of the respective provider.

13. Recipients of external connections

Depending on the function used, ImageKit, open.er-api.com, a speech service configured by the user or the relevant operating-system provider may receive technical data. Lemar does not transmit personal learning profiles for advertising, analytics or tracking purposes.

14. Data subject rights

Where the legal requirements are met, data subjects may have rights including access, rectification, erasure, restriction of processing, data portability and objection. Consent may be withdrawn with effect for the future.

Privacy requests can be sent to infinityvision.global@gmail.com. Data subjects also have the right to lodge a complaint with a competent data protection supervisory authority.

15. Hosting of this website

This public page is provided through GitHub Pages. When it is accessed, GitHub processes technically necessary connection data. This page itself does not include our own analytics or advertising technologies.

16. Changes

This Privacy Policy may be updated if Lemar's functions or data-processing activities change.
